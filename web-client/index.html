Supabase RLS Blocked Deletion

Your online Supabase database has Row Level Security (RLS) active without a DELETE policy for client apps. Supabase blocked the delete query, so the records remain on the server.

1-Click SQL Fix (Supabase SQL Editor) 
ALTER TABLE public.attendance_logs DISABLE ROW LEVEL SECURITY;
ALTER TABLE public.employees DISABLE ROW LEVEL SECURITY;
How to apply in 10 seconds:
1. Open your Supabase Dashboard → SQL Editor.
2. Click New Query, paste the 2 lines above, and click Run.
3. Return here and click Execute Total Reset again.
